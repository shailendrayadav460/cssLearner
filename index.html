Level 1

CSS Kya Hota Hai? 🎨

CSS ka full form hai Cascading Style Sheet. Yeh ek styling language hai — programming language nahi! Iska kaam hota hai HTML ke content ko sundar banana. Jaise ghar ka structure HTML se banta hai, lekin furniture aur paint CSS se lagta hai!

🏗️
HTML – Structure
Yeh page ka skeleton banata hai. Jaise ek khaali kamra — walls, doors, windows.
🎨
CSS – Style
Yeh page ko sundar banata hai. Rang, font, spacing — sab CSS karta hai.
⚡
JS – Logic
Yeh page ko interactive banata hai. Button click pe kuch ho — yeh JS ka kaam hai.

Basic Syntax

CSS likhne ka ek simple rule hota hai:

CSS
/* selector { property: value; } — yeh basic format hai */ h1 { color: red; /* text ka rang */ font-size: 24px; /* text kitna bada */ } /* Selector → kaun se element pe style lagnaa chahiye Property → kya change karna hai Value → kitna ya kaise change karna hai Semicolon → ek property khatam, nayi shuru */
💡 Yaad Rakho Semicolon (;) bohot zaroori hai! Har property ke baad lagaao. Bhool gaye toh next property kaam nahi karega.

CSS Include Karne Ke 3 Tarike

1️⃣
Inline Style
Element ke andar seedha likhte hain.
<h1 style="color:red">

❌ Recommended nahi — every element pe baar baar likhna padta hai.
2️⃣
<style> Tag
HTML file ke <head> mein <style> tag ke andar CSS likhte hain.

✅ Chhote projects ke liye theek hai.
3️⃣
External Stylesheet ⭐
Alag .css file banao aur HTML se link karo.

✅ Best way! Code clean rehta hai, ek jagah se sab control hota hai.
HTML – External Stylesheet Link
<!-- HTML ke head mein yeh likhte hain --> <link rel="stylesheet" href="style.css"> /* ⚠️ Priority order: Inline > <style> tag > External Matlab inline style sabse zyada powerful hoti hai */

Selectors – Kisko Style Dena Hai? 🎯

Selector batata hai ki kaunse HTML element ko style dena hai. Yeh CSS ka pehla part hota hai.

Selector Type Syntax Matlab Example Use
Universal * { } Page pe har ek element ko select karo * { margin: 0; padding: 0; }
Element h1 { } Specific HTML tag ko select karo h1 { color: red; }
ID #myId { } Ek specific element (unique hota hai page pe) #header { background: black; }
Class .myClass { } Same class wale sab elements (multiple ho sakte hain) .card { border: 1px solid; }
CSS – Selectors Example
/* Universal Selector – sabko pakdo */ * { box-sizing: border-box; } /* Element Selector – sirf h1 tags */ h1 { color: red; } /* ID Selector – sirf woh element jiska id="box" hai */ #box { background-color: blue; } /* Class Selector – sab elements jinke class="heading" hai */ .heading { font-size: 24px; }
⚠️ ID vs Class ID (#) ek page pe sirf ek baar use hoti hai — unique hoti hai. Class (.) multiple elements pe use ho sakti hai. Mostly class use karo!

Text Properties – Likhawat Sundar Banao ✍️

Text ke style ke liye yeh properties use hoti hain.

PropertyValuesKya Karta Hai
text-align left / right / center Text ko left, right ya center mein align karo (parent ke relative)
text-decoration underline / overline / line-through / none Text pe line lagao — neeche, upar, ya beech mein. Links pe none use karo.
font-weight normal / bold / 100–900 Text kitna mota (bold) ho. 400 = normal, 700 = bold.
font-size 16px / 1rem / 2em Text ka size. 96px = 1 inch.
font-family arial / roboto / "Times New Roman" Font ka naam. Multiple dene se fallback hota hai.
line-height 2px / 1.5 / normal Lines ke beech space kitna ho.
text-transform uppercase / lowercase / capitalize / none Text ko UPPER, lower, ya Capitalize karo automatically.
CSS – Text Properties
h1 { text-align: center; text-transform: uppercase; /* auto CAPS */ font-family: arial, roboto; /* fallback mechanism */ font-weight: 700; /* bold */ text-decoration: none; /* links ki underline hatao */ line-height: 1.5; /* comfortable reading */ }
💡 Font Families 5 generic font families hoti hain: Serif, Sans-Serif, Cursive, Fantasy, Monospace. Google Fonts pe jaao bohot saare free fonts milenge!
Level 2

Box Model – Har Element Ek Box Hai! 📦

CSS mein har element ek box ki tarah hota hai. Is box ke 4 layers hoti hain: Content → Padding → Border → Margin. Yeh samajhna sabse zaroori concept hai!

Content
📄
Content
Actual content — text, image etc. width aur height isi ka size set karta hai.
🛋️
Padding
Content aur border ke beech ka space. Inside element ke andar hota hai. Background color dikhti hai padding mein.
🖼️
Border
Element ke chaaro taraf ki line/rekha. Width, style, color set kar sakte hain.
↔️
Margin
Element ke bahar ka space. Doosre elements se duri banata hai.
CSS – Box Model Properties
div { /* Size */ width: 200px; height: 100px; /* Border – width | style | color */ border: 2px solid black; /* shorthand */ border-radius: 10px; /* corners round karo */ border-radius: 50%; /* perfect circle! */ /* Padding – sab sides */ padding: 20px; /* sab taraf 20px */ padding: 10px 20px 10px 20px; /* top right bottom left */ /* Margin – same pattern as padding */ margin: 50px; margin: 0 auto; /* center karne ka trick! */ }
💡 Clockwise Rule (Ghadi Ki Sui) Jab 4 values dete hain: padding: top right bottom left — ghadi ki sui ki tarah. "TRBL" yaad rakho!

Display Property – Kaise Dikhega? 🖥️

Display property decide karti hai ki element page pe kaise behave karega.

➡️
inline
Sirf utni jagah leta hai jitni zaroorat hai. Margin/Padding set nahi hoti. Jaise: <span>, <a>
⬛
block
Poori width leta hai, nayi line se start hota hai. Jaise: <div>, <p>, <h1>
🔲
inline-block
Inline ki tarah side-by-side, lekin margin/padding kaam karti hai. Best of both!
👻
none
Element ko completely hata do. Koi space bhi nahi rehta. visibility: hidden se alag — woh space reserve karta hai.
CSS – Display
span { display: block; } /* inline ko block banao */ div { display: inline-block; } /* block ko inline-block banao */ .hidden { display: none; } /* element hatao */ /* Visibility vs Display */ .invisible { visibility: hidden; } /* dikhe nahi, jagah le */ .gone { display: none; } /* dikhe nahi, jagah bhi nahi */
Level 3

Position – Kahan Rakhein Element? 📍

Position property element ko document mein kahan rakha jaayega yeh decide karti hai. Iske saath top, right, bottom, left, z-index use hote hain.

ValueKya Karta HaiTop/Left Kaam Karta?
static Default position. Normal page flow mein rehta hai. ❌ Nahi
relative Khud ki original position ke relative move karta hai. ✅ Haan
absolute Sabse paas ke positioned ancestor ke relative. Page flow se hata jaata hai. ✅ Haan
fixed Browser window ke relative. Scroll karo toh bhi nahi hilta (e.g. navbar). ✅ Haan
sticky Normal flow mein rehta hai, scroll pe ek jagah chipak jaata hai. ✅ Haan
CSS – Position Examples
/* Fixed Navbar – scroll pe bhi upar rehta hai */ nav { position: fixed; top: 0; left: 0; width: 100%; z-index: 100; /* sabke upar dikhe */ } /* Absolute inside relative – common pattern */ .parent { position: relative; } .child { position: absolute; top: 0; right: 0; /* parent ke top-right corner mein */ }
💡 Z-Index Kya Hai? Z-index 3D layer decide karta hai. Zyada z-index wala element upar dikhai deta hai. Sochao jaise paper ke stacks — jis par zyada number, woh upar.

Units – Kitna Bada? 📏

CSS mein size dene ke liye alag-alag units use hoti hain.

🔵
px (Pixels) – Absolute
Fixed size. Screen pe har jagah same dikhega. 96px = 1 inch. Sabse zyada use hota hai.

font-size: 16px;
📊
% – Relative to Parent
Parent element ke size ke relative. Parent 500px hai toh 50% = 250px.

width: 50%;
🔤
em – Relative to Parent Font
Parent ke font-size ke relative. Nested elements mein chain create hoti hai.

font-size: 1.5em;
🌐
rem – Root Em
Root element (<html>) ke font-size ke relative. Consistent rehta hai. Best for responsive design!

font-size: 1rem;
📱
vh / vw
Viewport ki height/width ke 1% ke relative.
100vh = poori screen height.

height: 100vh;
⚠️ Em vs Rem em parent ke font-size pe depend karta hai — nested elements mein complex ho jaata hai. rem root pe depend karta hai — predictable aur simple hai. Beginners ke liye rem better hai!

Flexbox – Layout Ka Jadoo ✨

Flexbox ek layout system hai jo elements ko row ya column mein arrange karta hai. Pehle parent ko display: flex dena padta hai — phir sab magic hota hai!

justify-content: flex-start (default)
A
B
C
CSS – Flexbox
/* Step 1: Parent ko flex banao */ .container { display: flex; /* Direction – kis direction mein items jaayen */ flex-direction: row; /* default: left se right */ flex-direction: column; /* upar se neeche */ /* Main Axis (horizontal by default) alignment */ justify-content: center; /* beech mein */ justify-content: space-between; /* dono ends pe push */ justify-content: space-evenly; /* equal space */ /* Cross Axis (vertical by default) alignment */ align-items: center; /* vertically center */ align-items: flex-start; /* upar */ align-items: flex-end; /* neeche */ /* Wrap – fit na ho toh next line mein jaao */ flex-wrap: wrap; } /* Step 2: Child items pe properties */ .item { flex-grow: 1; /* available space le lo */ flex-shrink: 0; /* chhota mat ho */ align-self: center; /* sirf is item ko center karo */ } /* Div ko perfectly center karna – popular trick! */ .parent { display: flex; justify-content: center; align-items: center; }
💡 Align-items vs Align-self align-items saare flex items pe lagti hai. align-self sirf ek item pe — aur yeh zyada powerful hai, align-items ko override karta hai!

Media Queries – Responsive Design 📱

Aajkal log website mobile pe bhi dekhte hain, laptop pe bhi. Media queries se hum alag screen sizes ke liye alag styles likh sakte hain — website responsive ban jaati hai!

Common breakpoints:

< 480px
📱 Mobile
481–768px
📟 Tablet
769–1024px
💻 Laptop
> 1024px
🖥️ Desktop
CSS – Media Queries
/* Sirf 600px pe */ @media (width: 600px) { div { background-color: red; } } /* 600px aur uske upar wale screens pe */ @media (min-width: 600px) { div { background-color: blue; } } /* Range – 200px se 300px ke beech */ @media (min-width: 200px) and (max-width: 300px) { div { background-color: green; } } /* Mobile first approach – pehle mobile style, phir bade screens ke liye */ div { font-size: 14px; } /* mobile default */ @media (min-width: 768px) { div { font-size: 18px; } /* tablet aur bade */ }

Transitions – Smoothly Change Karo 🌊

Neeche wale button pe hover karo!

CSS – Transitions
button { background: orange; /* property | duration | timing | delay */ transition: all 0.3s ease-in-out 0s; } button:hover { transform: scale(1.1); background: darkorange; /* Transition automatically smooth animation karega! */ } /* Timing functions: ease = slow → fast → slow linear = uniform speed ease-in = slow start ease-out = slow end */
