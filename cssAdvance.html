Level 1

What is CSS? 🎨

CSS stands for Cascading Style Sheet. It is a styling language — not a programming language. Its job is to make HTML content look beautiful. Think of HTML as the bare structure of a house and CSS as the paint, furniture, and decoration.

🏗️
HTML – Structure
Provides the skeleton of the page — walls, doors, windows. No styling at all.
🎨
CSS – Style
Makes everything look good — colors, fonts, spacing, layout. This is what CSS does.
⚡
JS – Logic
Adds interactivity — button clicks, form validation, dynamic updates.

Basic Syntax

CSS
/* selector { property: value; } ← the golden formula */ h1 { color: red; /* changes text color */ font-size: 24px; /* changes text size */ } /* Selector → which element to style Property → what to change Value → how to change it Semicolon → marks end of one property (always add it!) */

3 Ways to Add CSS

1️⃣
Inline Style
Written directly on the element using the style="" attribute.

❌ Not recommended — repetitive and messy.
2️⃣
<style> Tag
CSS written inside a <style> tag in the same HTML file.

✅ Okay for small projects.
3️⃣
External Stylesheet ⭐
CSS in a separate .css file, linked to the HTML.

✅ Best practice — clean, reusable, maintainable.
⚠️ Priority Rule Inline style > <style> tag > External stylesheet. Inline always wins because it has the highest specificity.
HTML – Linking an External Stylesheet
<link rel="stylesheet" href="style.css"> <!-- goes inside <head> -->

Selectors 🎯

A selector tells CSS which HTML element(s) to apply styles to. It is the first part of every CSS rule.

TypeSyntaxWhat it targetsExample
Universal* { }Every single element on the page* { box-sizing: border-box; }
Elementh1 { }All elements of a specific HTML tagh1 { color: red; }
ID#myId { }One unique element with that id#header { background: black; }
Class.myClass { }All elements sharing that class name.card { border-radius: 8px; }
⚠️ ID vs Class An ID (#) must be unique — use it only once per page. A Class (.) can be shared across many elements. In practice, prefer classes.
CSS – All Selector Types
* { box-sizing: border-box; } /* universal */ h1 { color: red; } /* element */ #box { background: blue; } /* id */ .heading { font-size: 24px; } /* class */

Text Properties ✍️

Properties that control how text looks — alignment, decoration, weight, size, and more.

PropertyCommon ValuesWhat it does
text-alignleft / right / centerAligns text within its parent container.
text-decorationunderline / overline / line-through / noneAdds decorative lines. Use none to remove underline from links.
font-weightnormal / bold / 100–900Controls how thick/bold the text is. 400 = normal, 700 = bold.
font-size16px / 1rem / 2emSize of the text. 96px = 1 inch.
font-familyarial / roboto / "Times New Roman"Which font to use. List multiple as fallbacks.

CSS – Text Properties
h1 { text-align: center; text-transform: uppercase; font-family: arial, roboto; /* roboto is the fallback */ font-weight: 700; text-decoration: none; /* removes default underline from links */ line-height: 1.6; }
💡 Generic Font Families CSS has 5 generic font families: Serif, Sans-Serif, Cursive, Fantasy, Monospace. Always end your font-family list with a generic name as the final fallback.
Level 2

The Box Model 📦

Every element in CSS is a rectangular box with four layers: Content → Padding → Border → Margin. Understanding this is the most fundamental concept in CSS.

Content
📄
Content
The actual text or image. width and height set the size of this area by default.
🛋️
Padding
Space between content and border — inside the element. Background color shows through padding.
🖼️
Border
The visible outline around the element. You control width, style, and color.
↔️
Margin
Space outside the border. Creates distance between this element and its neighbors.
CSS – Box Model Properties
div { width: 200px; height: 100px; /* Border shorthand: width | style | color */ border: 2px solid black; border-radius: 10px; /* rounded corners */ border-radius: 50%; /* perfect circle! */ /* Padding shorthand */ padding: 20px; /* all 4 sides */ padding: 10px 20px; /* top+bottom | left+right */ padding: 5px 10px 15px 20px; /* top right bottom left (clockwise) */ /* Margin – same pattern as padding */ margin: 0 auto; /* classic center-align trick for block elements */ }
💡 Clockwise Rule – TRBL When you pass 4 values: Top → Right → Bottom → Left, going clockwise. Easy to remember!

Display Property 🖥️

Controls how an element behaves in the page flow — how much space it takes and whether it starts on a new line.

➡️
inline
Takes only the space it needs. Elements sit side by side. Margin/padding top & bottom don't work. e.g. <span> <a>
⬛
block
Takes full available width. Always starts on a new line. e.g. <div> <p> <h1>
🔲
inline-block
Sits inline like text BUT respects width, height, margin, and padding. Best of both worlds.
👻
none
Completely removes element — no space reserved. Different from visibility: hidden which hides but keeps space.
Level 3

Position Property 📍

Controls exactly where an element is placed on the page. Works with top, right, bottom, left, and z-index.

ValueBehaviortop/left work?In page flow?
staticDefault. Element stays where the browser puts it.❌ No✅ Yes
relativeMoves relative to its own normal position.✅ Yes✅ Yes
absolutePlaced relative to nearest positioned ancestor. Removed from flow.✅ Yes❌ No
fixedRelative to the browser viewport. Stays put on scroll.✅ Yes❌ No
stickyActs like relative until a scroll threshold, then sticks.✅ Yes✅ Yes
CSS – Position Examples
/* Fixed navbar — stays at top even on scroll */ nav { position: fixed; top: 0; left: 0; width: 100%; z-index: 1000; /* sit above everything */ } /* Classic pattern: absolute inside relative */ .parent { position: relative; } .badge { position: absolute; top: 8px; right: 8px; /* pins to parent's top-right corner */ }
💡 z-index z-index controls which element sits on top when they overlap. Higher value = appears on top. Only works on positioned elements (not static).

Units in CSS 📏

CSS supports both absolute and relative units. Choosing the right unit matters for responsive design.

🔵
px – Pixels (Absolute)
Fixed size regardless of context. 96px = 1 inch. Most commonly used unit.

font-size: 16px
📊
% – Relative to Parent
Percentage of the parent element's size. If parent = 500px and child = 50%, child = 250px.

width: 50%
🔤
em – Relative to Parent Font
Relative to the parent's font-size for font-size; relative to the element's own font-size for other properties.

font-size: 1.5em
🌐
rem – Root Em
Always relative to the root <html> font-size. Consistent and predictable. Preferred for responsive design.

font-size: 1rem
📱
vh / vw – Viewport Units
1vh = 1% of viewport height. 1vw = 1% of viewport width. Great for full-screen sections.

height: 100vh
Level 4

Flexbox ✨

A one-dimensional layout system for arranging items in rows or columns. Apply display: flex to the parent/container — the children become flex items automatically.

justify-content: flex-start (default)
A
B
C
CSS – Flexbox Complete
/* ── Container Properties ── */ .container { display: flex; flex-direction: row; /* row | row-reverse | column | column-reverse */ justify-content: space-between; /* main axis alignment */ align-items: center; /* cross axis alignment */ flex-wrap: wrap; /* wrap items to next line if needed */ align-content: space-between; /* space between wrapped rows */ } /* ── Item Properties ── */ .item { flex-grow: 1; /* grow to fill available space */ flex-shrink: 0; /* don't shrink below natural size */ align-self: flex-end; /* override align-items for this one item */ } /* Perfect centering trick */ .parent { display: flex; justify-content: center; align-items: center; }
💡 align-items vs align-self align-items applies to ALL items in the container. align-self overrides it for ONE specific item — and it has higher priority.

Media Queries 📱

Apply different styles for different screen sizes, orientations, or devices. This is what makes websites responsive.

Common breakpoints:

< 480px
📱 Mobile
481–768px
📟 Tablet
769–1024px
💻 Laptop
> 1024px
🖥️ Desktop
CSS – Media Queries
/* Exact width */ @media (width: 600px) { ... } /* 600px and above */ @media (min-width: 600px) { ... } /* Between 300px and 600px */ @media (min-width: 300px) and (max-width: 600px) { ... } /* Mobile-first approach (recommended) */ div { font-size: 14px; } /* mobile default */ @media (min-width: 768px) { div { font-size: 18px; } /* tablet and above */ }

⭐ Bonus

Advanced CSS Used in This Website

This website itself uses many CSS techniques beyond what is covered in the notes. Below is a complete summary of every advanced technique used — what it is, why it is useful, and exactly where it appears on this page.

🎨 CSS Custom Properties (Variables)
--bg --accent --cyan var()
Defined with --name: value inside :root { } and used anywhere with var(--name). Changing one variable updates the entire site instantly — the foundation of theming.

Used here: All colors, backgrounds, and borders on this entire page use custom properties — var(--accent), var(--bg), var(--border), etc.
🌈 Radial & Linear Gradients
radial-gradient() linear-gradient() background
CSS gradients create smooth color transitions without any images. radial-gradient radiates from a center point; linear-gradient transitions along a straight line.

Used here: Hero section background uses two overlapping radial gradients (orange glow + cyan glow) to create the atmospheric lighting effect.
📐 CSS Grid Layout
display: grid grid-template-columns repeat() auto-fit minmax()
CSS Grid is a two-dimensional layout system. auto-fit with minmax() creates fully responsive grids without any media queries — columns automatically reflow as the viewport shrinks.

Used here: .page-layout (sidebar + main), .card-grid, .adv-grid — all built with CSS Grid.
📏 clamp() Function
clamp(min, preferred, max)
clamp() sets a value that scales fluidly between a minimum and maximum. Perfect for responsive typography without breakpoints — the browser calculates the ideal value automatically.

Used here: font-size: clamp(2.6rem, 7vw, 5.2rem) on the hero heading — it scales smoothly on all screen sizes.
🔁 Repeating Gradients (Grid Pattern)
repeating-linear-gradient()
Creates a repeating tile pattern using gradients — no image files needed. Combining horizontal and vertical repeating gradients produces a CSS grid/dot overlay.

Used here: The subtle grid dot pattern in the hero section background is made entirely with two overlapping repeating-linear-gradient() calls.
🎭 Pseudo-elements (::before / ::after)
::before ::after content: ''
Pseudo-elements insert virtual elements into the DOM via CSS alone — no extra HTML needed. They must have content set (even empty) and are often positioned absolutely for decorative effects.

Used here: Grid overlay in hero (.hero::before), labels in the box model diagram (.bm-margin::before), scroll hint arrow (.scroll-hint::after), decorative glow in advanced summary card (.adv-section::before).
🖱️ Pseudo-classes (:hover, :nth-child)
:hover :nth-child() :hover .child
Pseudo-classes apply styles based on element state or position without JavaScript. :hover triggers on mouse-over; :nth-child(n) targets a specific child in a list.

Used here: All card hover lifts, color swatch hover rotations, flex item colors (B = cyan, C = green via :nth-child), sidebar nav hover/active states, transform card hover effects, nav dot color changes.
🔢 CSS Animations (@keyframes)
@keyframes animation animation-delay
@keyframes define a named animation with states at various percentages (0%–100%). The animation shorthand attaches it to an element with duration, timing, delay, and iteration count.

Used here: 5 named animations: spin (loader), pulse, slideInOut, bounceUp, fadeDown (hero elements staggered with animation-delay), bounce (scroll hint arrow).
📌 position: sticky
position: sticky top: 0 height: 100vh
A sticky element scrolls normally until it reaches a threshold, then "sticks" in place. Here it keeps the sidebar fixed while the main content scrolls.

Used here: The left sidebar uses position: sticky; top: 0; height: 100vh to stay visible as you scroll through all chapters.
🌊 CSS Transitions
transition ease / linear transform
Transitions animate property changes between states (e.g. default → hover) smoothly. The shorthand order is: property | duration | timing-function | delay.

Used here: All card hover lifts, button hover scale/shadow, sidebar nav item highlights, color swatch rotations, nav dot color changes, flex demo container layout change, transform demo boxes — all use CSS transitions.
↕️ overflow & Custom Scrollbar
overflow: auto overflow-x: auto ::-webkit-scrollbar
overflow controls what happens when content exceeds its container. The ::-webkit-scrollbar pseudo-element family lets you fully style the scrollbar in Chrome/Edge/Safari.

Used here: The sidebar uses overflow-y: auto. The global orange scrollbar (::-webkit-scrollbar-thumb) and the horizontal code block scrolls (overflow-x: auto) also use these.
📦 box-shadow & rgba transparency
box-shadow rgba() inset
box-shadow adds drop shadows (or inner glow with inset). Combining with rgba() alpha values creates soft, realistic depth without hard edges.

Used here: Card hover states, button hover glow, color swatches, hero button primary shadow — all use box-shadow with rgba() transparency for soft effects.
📱 Media Queries (Responsive Layout)
@media (max-width: 900px) @media (max-width: 600px)
This website adapts to different screen sizes using two breakpoints. The sidebar is hidden on mobile, grid columns collapse, and padding reduces — all controlled purely with CSS media queries.

Used here: Below 900px → sidebar hidden, single-column layout. Below 600px → all card grids collapse to 1 column.
🔤 Google Fonts (@import / link)
Baloo 2 JetBrains Mono Nunito
External web fonts loaded via a <link> tag to Google Fonts CDN. Each font serves a specific role — display, code, and body — making the typography system cohesive.

Used here: Baloo 2 → all headings and level badges. JetBrains Mono → all code blocks, tags, and property chips. Nunito → all body text and UI elements.
🖥️ Inline JS for Interactive Demos
element.style classList scroll event
Not CSS itself, but closely linked — JavaScript is used to dynamically change CSS property values and class names, bridging the gap between CSS and interactivity.

Used here: Flexbox live demo (buttons set justifyContent), sidebar active state highlight on scroll, hover button inline style changes.
