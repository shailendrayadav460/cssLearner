# CSS Seekho – Hinglish Mein 🎨🚀

A comprehensive CSS learning guide written in **Hinglish** (Hindi + English), designed for college students learning web development.

## 📖 About

This is an interactive, single-page CSS tutorial that covers all major CSS concepts with simple Hinglish explanations, live demos, and practice sets. Inspired by **Apna College** teaching style.

## 📚 Topics Covered

- **Level 1 – CSS Basics**: Syntax, inline/internal/external CSS, priority
- **Colors**: Named colors, RGB, RGBA, Hex codes
- **Selectors**: Universal, Element, ID, Class selectors
- **Text Properties**: font-size, font-family, text-align, text-decoration, etc.
- **Level 2 – Box Model**: Content, Padding, Border, Margin
- **Display Property**: inline, block, inline-block, none
- **Level 3 – Position**: static, relative, absolute, fixed, sticky, z-index
- **Units**: px, %, em, rem, vh, vw
- **Level 4 – Flexbox**: justify-content, align-items, flex-wrap, flex-grow
- **Media Queries**: Responsive design for mobile, tablet, laptop, desktop
- **Level 5 – Advanced**: Transforms, Transitions, CSS Animations, @keyframes

## 🎯 Practice Sets

Includes 6+ practice sets covering:
- CSS Basics
- Text Properties
- Box Model (Circle, Navbar)
- Flexbox Layout
- Media Queries (responsive color changes)
- CSS Loader Animation

## 🛠️ Tech Stack

- Pure **HTML5**
- Pure **CSS3** (no frameworks)
- Vanilla **JavaScript** (for interactive demos)
- Google Fonts: Baloo 2, JetBrains Mono, Nunito

## 🚀 How to Use

1. Download or clone the file
2. Open `index.html` in any browser
3. Read each section and try the practice sets in a separate file
4. Use browser DevTools (F12) to experiment with styles

## ✨ Features

- 🌙 Dark theme UI
- 📱 Fully responsive sidebar + content layout
- 🎮 Interactive Flexbox demo (click buttons to see live changes)
- 🔄 Live CSS animation demos (spin, pulse, bounce, slide)
- 🖱️ Hover-based transform demos
- 📋 Quick reference cards at the end
- Smooth scroll + active sidebar highlighting
